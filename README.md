# Obilazak – izdanja

Instalacije sistema **Obilazak** (evidencija obilazaka parkinga NFC tagovima) – coded by [HMCode](https://hmcode.ba).
Izvorni kod je privatan; ovdje su samo instalacije.

| Fajl | Za |
|---|---|
| `Obilazak_<verzija>.apk` | Android aplikacija za službene telefone |
| `Obilazak_Server_Setup_<verzija>.exe` | Obilazak server za Windows Server |

Najnovije izdanje: [Releases → Latest](../../releases/latest).

Aplikacija i server same provjeravaju nova izdanja i ažuriraju se. Uz svaki fajl je `.sha256` sa kontrolnim zbirom;
`SHA256SUMS` je potpisan ključem izdavača i server ga provjerava prije instalacije.
